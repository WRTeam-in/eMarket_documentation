# App Logo

Setting the app icon is the same for every WRTeam app, so it is covered in our common setup guide:

👉 **[App Icon Setup](https://wrteam-in.github.io/common_app_doc/GeneralSettings/appicon)**

It covers both the automated method using `flutter_launcher_icons` and the manual method of replacing each size by hand.

:::note The partner app includes the icon generator
Unlike the customer app, the partner app still ships with the `flutter_launcher_icons` package, so you can use the automated method — configure it in `pubspec.yaml` and run the generator.
:::
