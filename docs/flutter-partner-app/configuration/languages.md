# Languages

You can manage all app and website languages from the admin panel — no code changes and no rebuild are needed.

1. Go to **Admin Panel → Language → Add Language** or **Manage Languages**

![Manage Languages](/img/flutter-partner-app/lan1.webp)

:::tip Labels and content are both translatable
Since version 3.0.0, translation covers data entries as well as interface labels, so category names, product names, and other content can be translated alongside the UI.
:::
