# Modules

Manage business modules available in admin panel from here. Navigate to **Modules** (General section).

## Overview

Table lists all modules with:

- **ID** — module identifier
- **Name** — module name (e.g. Grocery, Ecommerce, Pharmacy)
- **Image** — module icon
- **Description** — module description
- **Status** — enable/disable toggle
- **Actions** — edit module

## Enable/Disable Module

- Toggle **Status** switch on/off for any module
- Disabled module hidden from storefront/app, no longer selectable

## Reorder Modules

- Drag handle (⠿) on left of each row
- Drag row up/down to change display order
- Order reflects in module switcher across admin panel and app

## Edit Module

- Click edit (pencil) icon under **Actions**
- Update name, image, description
- Save changes

## Important Notes

- At least one module should remain enabled
- Reordering affects module switcher order everywhere, not just this list
