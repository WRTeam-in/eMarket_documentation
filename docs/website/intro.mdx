# Website Overview

Welcome to the eMarket Website documentation. This section provides information about the eMarket website, which serves as the frontend for customers to browse and shop online across Grocery, Pharmacy, and eCommerce modules.

## Introduction

The eMarket website is a comprehensive multi-vendor, multi-module shopping platform — covering Grocery, Pharmacy, and eCommerce modules that allows customers to:

- Browse products by categories
- Search for specific items
- Add products to cart
- Place orders
- Track order status
- Manage their account

This documentation will guide you through the features, setup, and customization options available for the eMarket website.
