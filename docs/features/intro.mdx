# Features

Browse the newest and most important topics across the eMarket platform — from multi-module operations to mobile app distribution.

:::tip What's New in the Latest Release
- ⚡ **Quick Delivery (15 & 30 Minutes)**: Ultra-fast hyper-local fulfillment options for rapid everyday essentials.
- 🍔 **Food Delivery Module**: Dedicated vertical with restaurant menus, dish addons, modifiers, and instant courier dispatch.
- 🛠️ **Seller-Level Attributes & Custom Fields**: Independent product attribute and custom field creation directly from the seller panel.
- 🎨 **Module-Wise Theme Color Management**: Distinct primary branding colors and accents per business vertical (Grocery, Food, Pharmacy, etc.).
- 🖼️ **Next-Gen WebP Image Support**: Native WebP compression across the Admin Panel and Customer Website for ultra-fast loading.
- 🌐 **Website Social Media Management**: Manage external social media links and channel icons directly from the Admin Panel.
- 🥗 **Dietary Markers (Veg / Non-Veg)**: Moved to dynamic custom fields for flexible dietary classification and allergen tagging.
- 📱 **Flutter 3.47.2 Modern Codebase**: Upgraded Customer and Partner apps for 120Hz smooth scrolling and latest OS security.
- ⚠️ **Seller Migration Alerts**: Automatic warnings for legacy global attributes to guarantee smooth vendor migration.
