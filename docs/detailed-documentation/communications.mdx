# Communications & Notifications

Multi-channel communication ensures customers, sellers, and delivery partners stay informed about order status changes, time-sensitive offers, and account security alerts. eMarket includes native engines for Push Notifications, Transactional Emails, and SMS alerts.

---

## 1. Send Push Notifications (`/notifications/create`)

![Send Notifications](/img/detailed-documentation/notifications-send.webp)

A broadcast messaging console for creating and sending real-time Firebase Cloud Messaging (FCM) push notifications directly to user smartphones.

### Step-by-Step Campaign Broadcast
1. Select the **Target Audience**:
   - **All Registered Customers**: Sitewide promotional announcements.
   - **Specific Customer Segment**: Target active buyers or users in specific cities.
   - **All Sellers** or **Delivery Partners**: Operational platform announcements.
2. Enter the **Notification Title** (short, compelling hook).
3. Compose the **Notification Message** body.
4. Upload an optional high-resolution **Notification Banner Image** to render as an expanded rich push notification on Android and iOS lock screens.
5. Set the **Target Redirection**:
   - Open specific Category, Product, or Promo Code page when tapped.
6. Click **Send Notification**. Delivery is instant across all registered FCM device tokens.

## 3. Automated Notification Templates (`/notification-templates`)

![Notification Templates](/img/detailed-documentation/notification-templates.webp)

Define the automated system notifications triggered during order lifecycle events.

### Built-In Dynamic Event Triggers
- `Order Received`: Dispatched to customer and vendor upon checkout.
- `Order Processed`: Informs the customer that packaging is underway.
- `Order Shipped / Out for Delivery`: Alerts customer with assigned courier details.
- `Order Delivered`: Confirmation alert with delivery timestamp.
- `Order Cancelled / Refunded`: Transparent notification of cancellation and refund credit.
- **Dynamic Placeholders**: Use tags like `{order_id}`, `{customer_name}`, and `{total_amount}` to auto-personalize every message.

## Real-World Communication Use Cases

- **Flash Sale App Push Notification**: At 11:00 AM on Sunday, the marketing team dispatches a rich push notification with an appetizing photo announcing "Free Delivery for the Next 2 Hours", producing an immediate 35% surge in app traffic.
- **Transactional Delivery Updates**: A customer at work receives an automated SMS and push notification the moment their order transitions to `Out for Delivery`, giving them time to prepare for courier handover.
- **Critical Vendor Stock Alerts**: Automated emails notify store managers whenever best-selling inventory drops below 5 units, prompting timely supplier re-stocking.
