# Abandoned Carts

Abandoned Carts shows sellers the products customers added to their cart but did not check out. Sellers can use it to see which products customers are interested in and follow up on them.

---

## 1. Abandoned Carts Page (Seller Panel)

Open **Abandoned Carts** from the seller panel menu.

![Abandoned Carts](/img/detailed-documentation/abandoned-carts.webp)

### Key Table Columns & Controls

| Column | Description |
|--------|-------------|
| **ID** | Cart entry ID. |
| **User** | Customer who added the product to the cart. |
| **Product** | Product left in the cart. |
| **Variant** | Selected variant, for example 1 KG or 50 KG. |
| **Quantity** | Quantity added to the cart. |
| **Added On** | Date and time the product was added to the cart. |
| **Actions** | Delete icon to remove the entry. |

### Page Controls

- **Search**: find an entry by typing in the search box.
- **Refresh**: reload the list.
- **Per page**: choose how many entries to show on each page.
- **Pagination**: move between pages. The total item count is shown at the bottom, for example *Showing Result 1–10 of 15 Items*.

---

## 2. Related Settings

Automated reminder notifications for abandoned carts are configured by the admin in **Store Settings → Cart Setting**. See [Cart Reminder](../admin-panel/cart-reminder.md).
