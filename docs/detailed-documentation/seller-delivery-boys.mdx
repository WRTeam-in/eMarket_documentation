# Seller-wise Delivery Boys

eMarket supports both **admin-wise** and **seller-wise** delivery boy management. With seller-wise management, each seller manages their own delivery boys (drivers) from the seller panel, separate from the delivery boys managed by the admin.

The seller panel has three menu items for this:

- **Delivery Boy Requests**
- **My Delivery Boys**
- **Delivery Boy Salary**

---

## 1. Delivery Boy Requests

![Delivery Boy Requests](/img/detailed-documentation/seller-delivery-boy-requests.webp)

Open **Delivery Boy Requests** from the seller panel menu to see requests from delivery boys.

- **Status filter**: filter the list by request status. The default view is **Pending**.
- **Refresh**: reload the list.

| Column | Description |
|--------|-------------|
| **ID** | Request ID. |
| **Name** | Delivery boy name. |
| **Mobile** | Delivery boy mobile number. |
| **Email** | Delivery boy email address. |
| **City** | City of the delivery boy. |
| **Status** | Current status of the request. |
| **Actions** | Actions available for the request. |

When there are no requests, the page shows "There are no records to show". The item count and pagination are shown at the bottom.

---

## 2. My Delivery Boys

![My Delivery Boys](/img/detailed-documentation/seller-my-delivery-boys.webp)

**My Delivery Boys** lists the delivery boys that belong to the seller.

### Page Controls

- **Card / List view**: switch between card view and list view using the two icons at the top right.
- **Refresh**: reload the list.
- **Add Delivery Boy**: add a new delivery boy.

### Delivery Boy Card

Each card shows:

- Name and profile initial
- Mobile number
- Email address
- City
- Delivery boy ID (for example `#37`)

At the bottom of each card:

- **Toggle**: enable or disable the delivery boy.
- **Edit** icon: edit the delivery boy details.
- **Delete** icon: delete the delivery boy.

---

## 3. Delivery Boy Salary

![Add Salary](/img/detailed-documentation/seller-delivery-boy-salary.webp)

**Delivery Boy Salary** records the salary paid to the seller's delivery boys.

### Page Controls

- **Search**: find a salary entry.
- **Filters**: filter the list.
- **Refresh**: reload the list.
- **Add Salary**: open the Add Salary form.
- **Per page**: choose how many entries to show on each page.

The list shows **ID**, **Delivery Boy**, **Date** and **Actions** for each salary entry.

### Adding a Salary

1. Click **Add Salary**.
2. Select the **Delivery Boy**.
3. Enter the **Salary** amount.
4. Select the **Date**.
5. Add an optional **Message**.
6. Click **Save**. Click **Cancel** to close the form without saving.
